# JezzBall
JezzBall - That addictive game on your Windows 3.1 machine, now back in full 64bit, reverse engineered glory!

The version that I chose to reverse engineer was the original 1992 Windows 3.1 release.  That is the version here.
The code could be cleaner, but reverse engineering never is really clean.  Lots of things that just had to be
done quickly.

But it all works well, is faithful and clean be cleaned up later.

Enjoy JezzBall!
